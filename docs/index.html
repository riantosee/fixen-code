Core Capabilities

Engineered for Autonomous Reliability

FIXEN CODE bridges LLMs with your real file system, git history, and terminal environment.

🔄

Real Agent Loop

Executes a real cognitive cycle: Understand ➔ Inspect ➔ Plan ➔ Execute ➔ Observe ➔ Reason ➔ Verify. Never stops after code generation alone.

⚡

Real-Time Token Streaming

Watch reasoning and drafts unfold with zero delay using an optimized native SSE parser and live terminal typing renderers.

🛡️

Atomic Transactions & Rollbacks

Multi-file changes are grouped inside atomic transactions. If any edit fails, all modifications automatically revert cleanly.

💾

Crash & Interruption Recovery

Automatic state checkpoints are saved at every step. If closed or killed, pick up seamlessly right where you left off with fixen resume.

🌿

Git Branch Checkpoints

Snapshots work on temporary checkpoint branches (fixen/checkpoint-*) before complex workflows, safeguarding your git working tree.

📱

Android Termux First-Class

Zero compiled native C++ bindings (no node-gyp). Runs smoothly on phones, tablets, servers, and developer workstations alike.
